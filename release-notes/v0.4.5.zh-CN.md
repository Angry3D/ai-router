# AI Router v0.4.5

## 重点更新

- 路由可选 Chat Completions 上游协议：应用会把 Responses 请求桥接为上游 /chat/completions，Codex 和本地客户端仍按原契约获得 POST /v1/responses；不透明 reasoning、更丰富的网页搜索声明、远程压缩和非流式客户端请求仍失败关闭。
- Codex 设置新增只读「模型价格」小节与手动「同步官网」：从 developers.openai.com 定价页同步 GPT 价格并与内置基线合并；失败时保留上一次的本地价格表，历史请求费用不会重算。内置价格目录同步加入 GPT-6 Sol/Luna。
- 路由设置新增「模型探索」：用当前表单中的 Base URL、API Key 与上游协议一次性获取上游模型列表，作为可搜索建议供「自定义模型」和「跳过 Fallback 的模型」选择，仍可手填任意模型 ID（结果不持久化，失败为软失败）。

## 注意事项

- Codex 兼容性验证基线更新至 Codex CLI 0.157.1。
- 无需手动迁移配置；应用内安装更新后仍需确认重启，才能运行新版。
