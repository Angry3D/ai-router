# AI Router release v0.4.7

## Highlights

- New "Codex credentials": one click generates and replaces the Codex credential file from a signed-in ChatGPT session in your local Chrome, solving Codex being unusable when the official sign-in flow cannot complete.

## Notices

- Chrome-based browsers only (currently verified with Google Chrome only); the first use shows a keychain prompt, so choose "Always Allow".
- Generated credentials are one-time: re-export after they expire, and restart Codex for the replacement to take effect (the app does not restart it).
- The original credentials are backed up automatically before replacement, and Settings can "Restore original credentials" at any time.
- If Codex uses non-file credential storage such as a keyring (or is locked by enterprise configuration), the feature refuses to write and gives guidance on what to change.
