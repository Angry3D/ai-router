# AI Router v0.4.0

## 重点更新

- 路由新增菜单显示开关，关闭后会同时退出顶部菜单和自动 Fallback，便于保留暂时不用的路由。
- 用量费用估算支持 GPT-6 Astra，并同步官网已列出模型的 Standard/Fast 费率；历史已保存费用不会重新计算。
- 自定义模型明确标注模型 ID 为必填，未填写上下文窗口时统一使用 256000 Token。

## 问题修复

- 修复上游仅返回图片 URL 时 Images MCP 无法取得生成结果的问题，支持下载并保存为本地 PNG 图片。

## 注意事项

- 移除每条路由的 Service Tier 设置，所有新请求统一保留 Codex 传入的服务层级；之前选择“移除参数”的路由升级后也按此方式转发。
- 当前激活路由不能隐藏；关闭路由显示后，若有效参与者少于两条，自动 Fallback 会关闭。
- 现有路由升级后默认保持显示，配置会自动迁移，原有路由配置和用量历史保留。
- Codex 兼容性验证基线更新至 Codex CLI 0.153.4。
- 应用内安装更新后仍需确认重启，才能运行新版。
