# AI Router release v0.4.0

## Highlights

- Routes gain a menu display switch; turning it off removes the route from the top menu and from automatic Fallback at the same time, making it easy to keep a route you do not currently need.
- Usage cost estimates support GPT-6 Astra and sync the Standard/Fast rates for models listed on the official site; historical saved costs are not recalculated.
- Custom models clearly mark the model ID as required, and a missing context window defaults to 256000 tokens.

## Fixes

- Fixed Images MCP being unable to obtain a generated result when the upstream only returned an image URL; it now downloads and saves the image as a local PNG file.

## Notices

- The per-route Service Tier setting is removed; all new requests keep the service tier passed by Codex, and routes that previously chose "remove parameter" forward the same way after upgrade.
- The active route cannot be hidden; when route display is turned off and fewer than two valid participants remain, automatic Fallback is turned off.
- Existing routes stay visible by default after upgrade, configuration migrates automatically, and existing route configuration and usage history are preserved.
- The Codex compatibility verification baseline is updated to Codex CLI 0.153.4.
- After installing an in-app update you still confirm the restart before the new version runs.
