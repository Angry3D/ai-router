# AI Router v0.4.3

## 重点更新

- 主库出现仅索引类损坏时自动重建索引并复检，通过后照常启动，不再进入恢复流程，也不会丢失请求历史；设置页会显示最近一次自动修复记录。
- 自定义模型的推理档位新增 max，并把默认档位从 high 改为 max；所选档位按原样发送给上游模型。
- 应用内更新的检查与下载改为跟随全局出站代理设置，在必须经代理访问 GitHub 的网络中也能完成检查与安装。

## 问题修复

- 数据库索引异常此前一律判定为需要恢复，可能造成请求历史丢失；现在只有表级或页级错误才会进入恢复流程。
- 更新检查与下载此前绕过全局出站代理，在只能经代理访问外网的环境下会持续失败。

## 注意事项

- 已连接 Codex 的用户需要在 Codex 中重启后，才能在模型列表看到新增的推理档位。
- 未显式设置推理档位的会话现在以 max 发起请求；如需改回较低档位，请在 Codex 中显式选择。
- 无需手动迁移配置；应用内安装更新后仍需确认重启，才能运行新版。
