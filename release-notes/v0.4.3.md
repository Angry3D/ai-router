# AI Router release v0.4.3

## Highlights

- Index-only corruption in the main database now rebuilds and rechecks the index, then starts as usual instead of entering recovery without losing request history; Settings shows the latest automatic repair.
- Custom models add a max reasoning tier and move the default tier from high to max; the selected tier is sent to the upstream model as-is.
- In-app update checks and downloads now follow the global outbound proxy setting, so they complete on networks that must go through a proxy to reach GitHub.

## Fixes

- Database index anomalies were previously always treated as requiring recovery, which could lose request history; now only table-level or page-level errors enter the recovery flow.
- Update checks and downloads previously bypassed the global outbound proxy and kept failing in environments that can reach the internet only through a proxy.

## Notices

- Users with Codex connected must restart Codex to see the new reasoning tier in the model list.
- Sessions that do not set a reasoning tier explicitly now request with max; choose a lower tier explicitly in Codex to change back.
- No manual configuration migration is needed; after an in-app update you still confirm the restart before the new version runs.
