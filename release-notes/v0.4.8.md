# AI Router release v0.4.8

## Highlights

- Fixed generated images failing to save even though generation succeeded when some upstreams returned a direct image link: the link is now downloaded directly, verified for integrity, and saved as a standard PNG.

## Fixes

- Fixed pricing information sometimes continuing to show a stale snapshot when a window is refocused; it now refreshes automatically on focus.

## Notices

- Direct image links are downloaded by this machine and never forward the generation API credentials; image sources that need an extra login session may still be unavailable.
