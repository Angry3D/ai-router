# AI Router release v0.4.1

## Highlights

- System Settings adds a global outbound proxy that can reach external services over HTTP, HTTPS, or SOCKS5.
- After the global proxy setting changes, later inference, balance, model discovery, and image generation requests take effect immediately with no app restart.
- Settings page titles are pinned above the scrolling content area, making positioning easier while the System, Codex, and Usage pages scroll.

## Notices

- The proxy is used only for external requests; AI Router's local loopback addresses keep a direct connection.
- Downloading generated image URLs keeps using a direct connection with DNS safety checks and does not go through the global proxy.
- No manual configuration migration is needed; the app does not restart automatically after installation.
