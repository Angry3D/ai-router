# AI Router release v0.3.0

## Highlights

- Settings can control how the menu bar is displayed, and the route editing form is more compact and marks required fields more clearly.
- The menu bar warns when generated images approach the capacity threshold and links straight into settings, and image upstream failures give a clearer reason.
- The menu bar request activity state is more stable, with more prominent activity icon feedback that stays continuous across tool calls.

## Fixes

- Fixed the menu bar activity animation lingering or stopping early when route status refreshes.
- Fixed error handling at the boundary between generated-image capacity and local state sync, so upstream failures are no longer misreported as success.

## Notices

- No configuration migration is needed, and the app does not restart automatically after installation.
