# AI Router release v0.4.4

## Highlights

- In-app updates now check the version recorded in the installer signature against the update notes and refuse to install on a mismatch or a missing record, so a tampered update response cannot point the update at an older version.

## Notices

- This verification takes effect from this version; upgrading from an earlier version to this one still completes through the existing flow with no extra action.
- No manual configuration migration is needed; after an in-app update you still confirm the restart before the new version runs.
