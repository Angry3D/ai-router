# AI Router release v0.4.9

## Highlights

- The outbound proxy now follows the system by default: inference, image generation and download, and app updates use macOS manual HTTP/HTTPS/SOCKS proxies and bypass rules, so a proxy address usually no longer needs to be entered by hand.

## Notices

- Settings mode names become "Follow system" and "Custom proxy"; a configuration previously disabling custom proxy now means follow system, so requests use the proxy when the system has a manual proxy, and a custom proxy remains selectable.
- PAC/WPAD automatic proxies are not used: when only an automatic proxy is available a request fails and suggests switching to a custom proxy.
- Price sync and Codex session retrieval still use the system network stack and are not controlled by the custom proxy setting.
- The Codex automatic compatibility check baseline is updated to codex-cli 0.160.0; other versions may work but are not guaranteed.
