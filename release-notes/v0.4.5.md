# AI Router release v0.4.5

## Highlights

- Routes may select a Chat Completions protocol, bridging Responses to /chat/completions while Codex and local clients get POST /v1/responses; opaque reasoning, richer web search, remote compaction, and non-streaming requests fail closed.
- Codex Settings adds read-only "Model pricing" and manual "Sync from website". GPT prices merge from developers.openai.com into the built-in baseline; failures keep prior prices and never recalculate costs. The catalog adds GPT-6 Sol/Luna.
- Route settings adds "Fetch model list": one fetch from the form's Base URL, API Key, and protocol feeds searchable suggestions for "Custom models" and "Models skipped by fallback"; any model ID is typeable (no persistence, soft failure).

## Notices

- The Codex compatibility verification baseline is updated to Codex CLI 0.157.1.
- No manual configuration migration is needed; after an in-app update you still confirm the restart before the new version runs.
