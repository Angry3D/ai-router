# AI Router v0.4.7

## 重点更新

- 新增「Codex 凭证」：一键从本机 Chrome 的已登录 ChatGPT 会话生成并替换 Codex 凭证文件，解决无法完成官方登录流程时 Codex 不可用的问题。

## 注意事项

- 仅支持 Chrome 系浏览器（当前仅验证 Google Chrome）；首次使用会弹出钥匙串授权，请选择「始终允许」。
- 生成的凭证为一次性：过期后需重新导出；替换后请重启 Codex 生效（应用不会自动重启）。
- 替换前会自动备份原凭证，设置页可随时「还原原凭证」。
- 若 Codex 使用 keyring 等非文件凭证存储（或由企业配置锁定），该功能会拒绝写入并给出修改指引。
