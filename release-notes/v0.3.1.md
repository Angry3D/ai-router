# AI Router release v0.3.1

## Highlights

- The app checks for updates silently as soon as it reaches normal operation and keeps checking in the background within the same process.
- After a successful check it checks again every 24 hours; temporary network, update service, or metadata failures retry after 6 hours.

## Fixes

- The menu bar display switches now control the status text and request activity indicator accurately.
- Fixed the relay name and balance remaining in the menu bar after the status text was turned off.
- Fixed a static dot still showing during requests after the activity animation was turned off.

## Notices

- The Codex compatibility verification baseline is updated to Codex CLI 0.150.1.
- Background update checks also resume when database recovery reaches normal operation.
- Background checks never download, install, notify, or restart automatically; found updates are still surfaced through the existing menu and Settings red dot.
- No configuration migration is needed, and the app does not restart automatically after installation.
