# AI Router release v0.4.6

## Highlights

- Fixed "Sync from website": the website changed the display names of its pricing tiers on 2026-09-30, which made sync always fail; sync no longer depends on the site's displayed wording.

## Fixes

- A failed "Sync from website" now distinguishes a page-structure change (with a reason code), a price-table write failure, and an unreachable network rather than one generic error; failures keep prior prices and never recalculate costs.

## Notices

- No manual configuration migration is needed; after an in-app update you still confirm the restart before the new version runs.
