# AI Router release v0.4.2

## Highlights

- New "Image model" setting: choose the upstream model used by the Codex image generation tool (default gpt-image-2) or enter a custom model name; each model family validates its own size and quality parameters.
- The Usage page marks upstream model forwarding: the record list, request details, and menu usage preview show both the requested and the actual model whenever forwarding occurs.

## Notices

- The Codex compatibility verification baseline is updated to Codex CLI 0.155.1.
- No manual configuration migration is needed; after an in-app update you still confirm the restart before the new version runs.
